## 🧰 5 天要练出来的能力

| 能力 | 怎么练 | 面试怎么答 |

| 幂等 | Day 2 | "INSERT IGNORE 幂等键表，重复请求读上次响应" |
| Docker 起项目 | Day 5 | "Dockerfile 多阶段构建 + compose app/mysql/redis 三服务" |

## 🛡️ 不要做

### 不要花时间在

- ❌ 刷算法 / 背 8 大排序
- ❌ 从零学 K8s / k3s
- ❌ 再背一遍面试题
- ❌ 写完整的单元测试覆盖率到 80%
- ❌ 研究 vLLM / 模型训练

### 不要硬装

- ❌ 不熟 Go-Zero / Kratos —— 诚实说"Gin 熟，能对着文档切"
- ❌ 不熟 PHP / Laravel —— 老实说"前端转的，看得懂路由和 Controller"
- ❌ 不熟 ES —— "JD 写了，但我 5 天没准备，进组边用边学"

### 不要做

- ❌ 把整个 ChatGPT / Claude API 跑一遍当 demo（浪费时间）
- ❌ 写完美架构（先跑通，再重构）
- ❌ 通宵熬夜（17 号会废）

## ⚠️ 进组前必知

### 你会的
- 起 Gin 服务、写 SSE、调 LLM
- MySQL 增删改查、Redis 缓存 + 限流
- Docker Compose、README 文档

### 你不会的（第一周别装）
- PHP 存量项目（看懂就行）
- ES 全文检索（JD 提了，但你 5 天没练）
- K3s / K8s（看你是否真懂）
- Go-Zero / Kratos（JD 提了，但你没用过）
- 生产级稳定性（熔断、限流、链路追踪……只在 demo 规模跑过）

### 进组第一天要做的 4 件事

1. **把项目跑起来**（如果跑不起来，谈技术都是空的）
2. **找到"调大模型"的那一层**（client / service / llm.go）
3. **看错误是怎么返回、SSE 怎么写的**
4. **领一个最小票**：改 prompt / 加一个参数 / 补日志
