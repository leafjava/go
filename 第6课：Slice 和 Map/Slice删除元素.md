# Slice 删除元素详解

## 核心写法

Go 没有内置的 `remove` 方法，删除元素通过**切片拼接**实现——把要删的那个元素跳过去，前后拼起来。

```go
s = append(s[:i], s[i+1:]...)
```

## 逐步拆解

假设 `s := []string{"A", "B", "C", "D"}`，要删除下标 1 的 `"B"`。

### 第一步：`s[:1]` — 取前半部分

从开头取到下标 1（不含 1），得到 `["A"]`。

```
原始: ["A", "B", "C", "D"]
       0    1    2    3
s[:1] → ["A"]
```

### 第二步：`s[2:]` — 取后半部分

从下标 2 取到末尾，跳过下标 1，得到 `["C", "D"]`。

```
原始: ["A", "B", "C", "D"]
       0    1    2    3
s[2:] → ["C", "D"]
```

### 第三步：`append` 拼接

```go
append([]string{"A"}, "C", "D") → ["A", "C", "D"]
```

其中 `s[2:]...` 的 `...` 是把切片**展开**成一个个元素：

```go
append(x, []string{"C", "D"}...)   // 有 ... → append(x, "C", "D")  ✅
append(x, []string{"C", "D"})      // 无 ... → 编译错误              ❌
```

## 图示

```
删除前: ["A", "B", "C", "D"]
         0    1    2    3
         ←保留→ ↑ ←保留→

删除后: ["A", "C", "D"]
```

## 通用写法

```go
func remove[T any](s []T, i int) []T {
    return append(s[:i], s[i+1:]...)
}

// 使用
addresses = remove(addresses, 1)  // 删除下标 1
```

## 注意事项

- 删除操作会**修改底层数组**，如果有其他切片共享底层数组，可能被影响
- 删除后原切片末尾会残留旧值，但 len 减小后访问不到，不影响使用
- 如果需要保留原切片，先 `copy` 一份再操作
