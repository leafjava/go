# Q12: 项目中最难的技术问题？怎么解决的？

> 以 f(x) Protocol 杠杆交易为例，讲原子交易 + 闪贷 + 稳定币铸造。

---

## 一句话概括

f(x) Protocol 把同一笔抵押资产（如 stETH/WBTC）**数学上拆成两部分**——稳定币（fxUSD，拿收益，不担风险）+ 杠杆仓位（xPOSITION，担波动，让出收益），整个过程通过 **原子交易 + 闪贷** 在单笔链上交易中完成。

---

## 完整流程（以 USDC → WBTC 杠杆为例）

```
用户钱包
  │
  │ ① 发送 USDC
  ▼
┌──────────────────────────────────────────────────┐
│  f(x) Protocol Router 合约（一笔原子交易）         │
│                                                    │
│  ② Uniswap V3 换币                                │
│     部分 USDC → WBTC（作为初始抵押品）              │
│                    │                               │
│  ③ Morpho 闪贷                                    │
│     借入额外 WBTC（实现 5x~10x 杠杆）              │
│                    │                               │
│  ④ 存入 f(x) 金库（Vault/Position）               │
│     初始 WBTC + 闪贷 WBTC 一起存入                 │
│                    │                               │
│  ⑤ 铸造 (Mint) fxUSD                              │
│     协议根据 f(x) invariant 公式计算铸造量          │
│                    │                               │
│  ⑥ 用 fxUSD → Uniswap/Curve 换回 USDC            │
│                    │                               │
│  ⑦ 归还闪贷（本金 + 极低费用）                     │
│                    │                               │
│  ⑧ 交易结束，用户持有杠杆仓位                      │
│                                                    │
│  ⚠ 任何一步失败 → 全部回滚，用户零损失              │
└──────────────────────────────────────────────────┘
```

### 八个步骤详解

| 步骤 | 做什么 | 关键合约 |
|------|--------|---------|
| ① | 用户把 USDC 转给 Router | Router 合约 |
| ② | Router 调 Uniswap V3，把**部分** USDC 换成 WBTC（作为初始抵押品） | Uniswap V3 |
| ③ | 闪贷借入**额外** WBTC，实现目标杠杆倍数（如 5x） | Morpho |
| ④ | 初始 + 闪贷借的 WBTC **一起**存入 f(x) 金库 | f(x) Vault |
| ⑤ | 协议根据 invariant 公式铸造 fxUSD | f(x) Core |
| ⑥ | 用铸造的 fxUSD 去 DEX 换成 USDC | Uniswap / Curve |
| ⑦ | 归还闪贷本金 + 极低手续费 | Morpho |
| ⑧ | 用户获得杠杆仓位，交易结束 | —— |

## 为什么必须原子化？

```
❌ 不是原子的情况：

  ② 换币成功 ✓
  ③ 闪贷借 WBTC 成功 ✓
  ④ 存入金库成功 ✓
  ⑤ 铸币失败 ✗（价格波动导致 invariant 不满足）
  
  结果：用户的 WBTC 锁在金库里，借的闪贷还不上 = 资金损失


✅ 原子交易：

  ② ③ ④ ⑤ ⑥ ⑦ 打包在同一笔交易里
  
  任何一步 revert → 整笔交易回滚
  
  EVM 保证：用户的钱要么完整走完全流程，要么回到原点，不会卡在中间状态
```

**面试话术**："整个流程在一笔交易里完成，EVM 保证原子性——要么 8 步全部成功，要么全部回滚，不会有资金卡在中间状态。"

## 核心创新：一笔资产拆成两部分

这是 f(x) Protocol 和其他协议最不一样的地方：

```
                    同一笔 stETH / WBTC（抵押资产）
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
              ┌──────────┐       ┌──────────────┐
              │  fxUSD   │       │  xPOSITION   │
              │  稳定币   │       │  杠杆仓位     │
              ├──────────┤       ├──────────────┤
              │ 拿全部： │       │ 承担全部：    │
              │ staking  │       │ 价格波动      │
              │ yield    │       │              │
              │ 质押收益  │       │ 让出全部：    │
              │          │       │ staking yield │
              │ 无价格   │       │              │
              │ 波动风险 │       │ 清算风险极低  │
              └──────────┘       └──────────────┘
```

## 什么是 Staking Yield？

```
以太坊网络
  │
  │ 用户质押 ETH 帮助网络验证交易
  │
  ▼
网络发放 ETH 奖励（目前年化约 3%~5%）
  │
  ▼
这就是 staking yield —— 质押收益
  │
  ▼
在 f(x) Protocol 里，stETH 的 staking yield
全部定向给 fxUSD 持有者
```

## 通俗比喻：会生金蛋的黄金

```
你有一块会生金蛋的黄金（stETH）：

┌─────────────────────────────────────────────┐
│                                             │
│  普通人直接持有：                            │
│  自己拿金蛋 ✓  但金价涨跌全承担 ✗            │
│                                             │
│  f(x) Protocol 把它拆开：                    │
│                                             │
│  fxUSD 持有者 → 拿稳定美元 + 所有金蛋         │
│  （像买了保本理财，利息来自金蛋 + 杠杆手续费）  │
│                                             │
│  xPOSITION 持有者 → 享受高倍金价波动          │
│  （金蛋收益让出去了，但换来了高杠杆 + 低清算） │
│                                             │
└─────────────────────────────────────────────┘
```

## 为什么 fxUSD 能提供"真实收益"？

其他稳定币（如部分算法稳定币）靠发新 token 补贴收益 → 不可持续。

fxUSD 的收益来自**真实经济活动**：

```
fxUSD 收益来源
  │
  ├── ① stETH 质押收益（以太坊网络发 ETH 奖励）
  │
  └── ② 杠杆玩家付的手续费（xPOSITION 持有者
        为获得杠杆 + 低清算风险，让出自己的 staking yield）
```

**面试话术**："这就是 f(x) 最吸引人的地方——去中心化稳定币还能持续赚真实收益，收益来自底层 stETH 的质押奖励和杠杆方让出的 yield，不是靠印新 token 补贴。"

## STAR 法则面试回答

**S（场景）**：在做 f(x) Protocol 的杠杆交易时，用户用 USDC 一键开 5x WBTC 杠杆仓位，涉及 Uniswap 换币、Morpho 闪贷、f(x) 金库存入、fxUSD 铸币、DEX 换回还贷，一共 8 个步骤。

**T（任务）**：必须保证 8 步原子执行，任何一步失败全部回滚，用户资金不能卡在中间状态。

**A（行动）**：
- 所有步骤打包在一个 Router 合约调用中，EVM 保证原子性
- 闪贷（Flash Loan）实现"无本金借钱"——在一个交易里借、用、还，无需抵押
- 设置合理的滑点保护（最小输出量），防止价格被操控
- f(x) invariant 公式校验铸币量，数学上保证系统不坏账

**R（结果）**：
- 用户一笔交易完成杠杆开仓，体验丝滑
- 任意环节失败自动回滚，零资金风险
- fxUSD 持有者获得真实 staking yield，不需印新 token 补贴
- 杠杆仓位清算风险极低（因为 staking yield 作为缓冲）

## 关键概念速记

| 概念 | 一句话 |
|------|--------|
| 原子交易 | 多步操作打包成一笔链上 tx，全成功或全回滚 |
| 闪贷 | 一个交易里借、用、还，无需抵押，还不成功就回滚 |
| f(x) invariant | 协议数学公式，决定能铸多少 fxUSD |
| fxUSD | 稳定币，拿全部 staking yield，零波动 |
| xPOSITION | 杠杆仓位，担全部价格波动，让出 yield |
| staking yield | ETH 质押给网络验证者后获得的奖励 |
| 真实收益 | 收益来自底层资产产出，不是印新 token |
