# 5. 调用智能合约 — 步骤解析

本文档梳理了通过 Go 调用以太坊智能合约（以查询 USDT 余额为例）的完整流程。

---

## 整体概览

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 1. 连接节点  │ → │ 2. 准备参数   │ → │ 3. 构造调用   │ → │ 4. 发送请求   │
│  ethclient   │    │ 合约地址/ABI  │    │  Pack 编码    │    │ CallContract  │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
                                                                    │
                                                                    ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 7. 显示结果  │ ← │ 6. 格式化输出 │ ← │ 5. 解码结果   │ ← │  返回 bytes   │
│ fmt.Printf   │    │   decimals    │    │  big.Int      │    │               │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

---

## 步骤 1：连接以太坊节点

```go
client, err := ethclient.Dial("https://ethereum.publicnode.com")
if err != nil {
    log.Fatal(err)
}
defer client.Close()
```

| 项目 | 说明 |
|------|------|
| **作用** | 通过 JSON-RPC 连接到以太坊网络 |
| **ethclient.Dial** | 创建以太坊客户端，接受 HTTP/HTTPS 或 WebSocket URL |
| **参数** | RPC 端点地址，常见的有：`cloudflare-eth.com`、`ethereum.publicnode.com`、`eth.llamarpc.com` 等 |
| **defer** | 确保函数退出时释放连接资源 |

---

## 步骤 2：准备合约地址和用户地址

```go
tokenAddress := common.HexToAddress("0xdAC17F958D2ee523a2206206994597C13D831ec7")
userAddress := common.HexToAddress("0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb")
```

| 项目 | 说明 |
|------|------|
| **tokenAddress** | USDT 以太坊主网合约地址 |
| **userAddress** | 要查询余额的目标钱包地址 |
| **common.HexToAddress** | 将十六进制的地址字符串转换为 20 字节的 `common.Address` 类型 |

> `common.Address` 本质是 `[20]byte`，代表以太坊 20 字节地址。

---

## 步骤 3：准备并解析 ABI

```go
const erc20ABI = `[
    {
        "constant": true,
        "inputs": [{"name": "_owner", "type": "address"}],
        "name": "balanceOf",
        "outputs": [{"name": "balance", "type": "uint256"}],
        "type": "function"
    }
]`

parsedABI, err := abi.JSON(strings.NewReader(erc20ABI))
```

| 项目 | 说明 |
|------|------|
| **ABI（Application Binary Interface）** | 描述合约的接口——有哪些函数、参数类型、返回值类型，类似于其他语言中的 "接口定义" |
| **balanceOf** | ERC20 标准函数，接收一个地址，返回该地址的代币余额（`uint256`） |
| **abi.JSON** | 将 JSON 格式的 ABI 字符串解析为 Go 的 `abi.ABI` 结构体 |
| **为什么要 ABI？** | 智能合约在链上是字节码，ABI 告诉程序如何正确编码调用参数、解码返回值 |

---

## 步骤 4：编码函数调用

```go
data, err := parsedABI.Pack("balanceOf", userAddress)
```

| 项目 | 说明 |
|------|------|
| **Pack** | 按照 ABI 规范，将函数名和参数编码成二进制数据（calldata） |
| **"balanceOf"** | 要调用的函数名，必须在 ABI 中有定义 |
| **userAddress** | 传入 balanceOf 的参数 `_owner` |
| **返回值 data** | `[]byte` 类型，即构造好的 calldata，可直接放入交易或调用中 |

> Pack 内部流程：先通过函数签名 `balanceOf(address)` 计算 Keccak-256 哈希的前 4 字节作为函数选择器（`0x70a08231`），再按 ABI 编码规则拼接地址参数（补零至 32 字节）。

---

## 步骤 5：构造 CallMsg 并发送调用

```go
msg := ethereum.CallMsg{
    To:   &tokenAddress,
    Data: data,
}

result, err := client.CallContract(context.Background(), msg, nil)
```

| 字段 | 说明 |
|------|------|
| **CallMsg.To** | 目标合约地址（USDT 合约） |
| **CallMsg.Data** | 上一步 Pack 好的 calldata |
| **CallContract** | 发起 `eth_call` RPC 请求，在节点本地执行（不上链、不消耗 Gas） |
| **context.Background()** | 上下文控制，可设置超时和取消 |
| **第三个参数 nil** | 指定区块号，`nil` 表示使用最新区块（latest） |

> `eth_call` 是**只读**调用，不会产生交易、不消耗 Gas、不会被广播到全网。适用于查询链上状态。

---

## 步骤 6：解码返回值

```go
balance := new(big.Int)
balance.SetBytes(result)
```

| 项目 | 说明 |
|------|------|
| **result** | `CallContract` 返回的 `[]byte`，即 ABI 编码的 `uint256` 值 |
| **big.Int** | Go 的 `math/big` 大整数类型，因为以太坊的 `uint256` 可达 256 位，远超 `uint64` 范围 |
| **SetBytes** | 将大端序字节数组解析为大整数 |

---

## 步骤 7：显示结果

```go
fmt.Printf("USDT 余额: %s\n", balance.String())
```

输出的是**原始整数**（最小单位），USDT 有 6 位小数，因此需要除以 `10^6` 才能得到人类可读的数值。

---

## 完整代码

```go
package main

import (
    "context"
    "fmt"
    "log"
    "math/big"
    "strings"

    "github.com/ethereum/go-ethereum"
    "github.com/ethereum/go-ethereum/accounts/abi"
    "github.com/ethereum/go-ethereum/common"
    "github.com/ethereum/go-ethereum/ethclient"
)

const erc20ABI = `[
    {
        "constant": true,
        "inputs": [{"name": "_owner", "type": "address"}],
        "name": "balanceOf",
        "outputs": [{"name": "balance", "type": "uint256"}],
        "type": "function"
    }
]`

func main() {
    // 1. 连接以太坊节点
    client, err := ethclient.Dial("https://ethereum.publicnode.com")
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    // 2. 合约地址 & 用户地址
    tokenAddress := common.HexToAddress("0xdAC17F958D2ee523a2206206994597C13D831ec7")
    userAddress := common.HexToAddress("0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb")

    // 3. 解析 ABI
    parsedABI, err := abi.JSON(strings.NewReader(erc20ABI))
    if err != nil {
        log.Fatal(err)
    }

    // 4. 编码函数调用
    data, err := parsedABI.Pack("balanceOf", userAddress)
    if err != nil {
        log.Fatal(err)
    }

    // 5. 构造并发送调用
    msg := ethereum.CallMsg{
        To:   &tokenAddress,
        Data: data,
    }
    result, err := client.CallContract(context.Background(), msg, nil)
    if err != nil {
        log.Fatal(err)
    }

    // 6. 解码返回值
    balance := new(big.Int)
    balance.SetBytes(result)

    // 7. 显示结果
    fmt.Printf("USDT 余额: %s\n", balance.String())
}
```

## 关键知识点

| 概念 | 解释 |
|------|------|
| **ABI** | 合约的"API 文档"，定义了函数签名、参数和返回值的编码规则 |
| **函数选择器** | 函数签名 Keccak-256 的前 4 字节，用于标识调用哪个函数 |
| **calldata** | 调用合约时附带的编码数据 = 函数选择器 + 参数 |
| **eth_call** | 只读调用，在节点本地模拟执行，不产生交易 |
| **uint256** | 256 位无符号整数，需用 `math/big.Int` 容纳 |
| **ERC20** | 以太坊代币标准，定义了 `balanceOf`、`transfer`、`approve` 等接口 |
