# Go 指针与结构体详解

## 一、& 符号：取地址创建指针

`&` 符号表示**取地址**，创建一个**指针**。

## 二、两种创建结构体的方式

### 1. 创建值（不带 &）

```go
ethPayment := EthereumPayment{
    WalletAddress: "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
}
// ethPayment 的类型是 EthereumPayment（值类型）
```

### 2. 创建指针（带 &）⭐

```go
ethPayment := &EthereumPayment{
//            ^ 取地址符号
    WalletAddress: "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
}
// ethPayment 的类型是 *EthereumPayment（指针类型）
```

## 三、区别对比

```go
type EthereumPayment struct {
    WalletAddress string
    Balance       float64
}

// 方式1：值类型
payment1 := EthereumPayment{WalletAddress: "0x123"}
// payment1 类型: EthereumPayment

// 方式2：指针类型
payment2 := &EthereumPayment{WalletAddress: "0x123"}
// payment2 类型: *EthereumPayment

fmt.Printf("%T\n", payment1)  // 输出: main.EthereumPayment
fmt.Printf("%T\n", payment2)  // 输出: *main.EthereumPayment
```

## 四、为什么要用指针？

### 1. 可以修改原始数据

```go
// 值接收者 - 不会修改原始数据
func (e EthereumPayment) AddBalance(amount float64) {
    e.Balance += amount  // 只修改副本
}

// 指针接收者 - 会修改原始数据 ⭐
func (e *EthereumPayment) AddBalance(amount float64) {
    e.Balance += amount  // 修改原始数据
}

// 使用
payment := &EthereumPayment{Balance: 100}
payment.AddBalance(50)
fmt.Println(payment.Balance)  // 输出: 150（被修改了）
```

### 2. 避免大结构体的复制（性能优化）

```go
type LargeStruct struct {
    Data [1000000]int  // 很大的数据
}

// 传值 - 会复制整个数组（慢）
func processValue(l LargeStruct) {
    // ...
}

// 传指针 - 只复制地址（快）⭐
func processPointer(l *LargeStruct) {
    // ...
}
```

## 五、完整示例

```go
type Wallet struct {
    Address string
    Balance float64
}

// 指针接收者方法
func (w *Wallet) Deposit(amount float64) {
    w.Balance += amount
}

func main() {
    // 创建指针
    wallet := &Wallet{
        Address: "0x123",
        Balance: 100,
    }
    
    wallet.Deposit(50)
    fmt.Println(wallet.Balance)  // 输出: 150
}
```

## 六、等价写法

```go
// 写法1：直接用 &
ethPayment := &EthereumPayment{
    WalletAddress: "0x742d35Cc...",
}

// 写法2：先创建值，再取地址
ethPayment2 := EthereumPayment{
    WalletAddress: "0x742d35Cc...",
}
ethPaymentPtr := &ethPayment2  // 手动取地址
```

## 七、记忆技巧

- **不带 `&`** = 创建一个**实体**（值）
- **带 `&`** = 创建一个**指向实体的箭头**（指针）

```go
// 值：我就是钱包本身
wallet1 := Wallet{Balance: 100}

// 指针：我是指向钱包的地址
wallet2 := &Wallet{Balance: 100}
```

## 八、在 Web3 开发中的应用

通常用指针因为：
- ✅ 需要修改钱包余额
- ✅ 避免复制大型交易数据
- ✅ 符合 Go 的惯用法
