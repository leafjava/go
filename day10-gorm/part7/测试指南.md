# 钱包管理 API 测试指南

## 1. 启动服务

```powershell
cd D:\web3project\go\day10-gorm\part7
go run .
```

看到以下输出说明启动成功：
```
数据库连接成功
数据库迁移完成
[GIN-debug] Listening and serving HTTP on :8080
```

---

## 2. 接口总览

| 方法 | URL | 作用 |
|------|------|------|
| POST | `/wallets` | 创建钱包 |
| GET | `/wallets` | 查询钱包列表（可选 `?user_id=1` 筛选） |
| PUT | `/wallets/:id` | 更新余额 |
| DELETE | `/wallets/:id` | 删除钱包 |

---

## 3. 测试流程（按顺序执行）

### 3.1 创建钱包

```powershell
curl.exe -X POST http://localhost:8082/wallets -H "Content-Type: application/json" -d '{"user_id":1,"address":"0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb","network":"Ethereum"}'
```
curl.exe -X POST http://localhost:8082/wallets -H "Content-Type: application/json" -d "{\"user_id\":1,\"address\":\"0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb\",\"network\":\"Ethereum\"}"

返回：
```json
{
    "message": "钱包创建成功",
    "wallet": {
        "id": 1,
        "user_id": 1,
        "address": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
        "network": "Ethereum",
        "balance": 0,
        "created_at": "...",
        "updated_at": "..."
    }
}
```

### 3.2 再创建几个钱包用于测试

```powershell
# 第二个钱包（同用户）
curl.exe -X POST http://localhost:8080/wallets -H "Content-Type: application/json" -d '{"user_id":1,"address":"0xAbC1234567890123456789012345678901234567","network":"BSC"}'

# 第三个钱包（另一个用户）
curl.exe -X POST http://localhost:8080/wallets -H "Content-Type: application/json" -d '{"user_id":2,"address":"0xDeF1234567890123456789012345678901234567","network":"Polygon"}'
```

### 3.3 查询所有钱包

```powershell
curl.exe http://localhost:8080/wallets
```

### 3.4 按用户筛选

```powershell
curl.exe "http://localhost:8080/wallets?user_id=1"
```

只返回 user_id=1 的钱包。

### 3.5 更新余额

```powershell
curl.exe -X PUT http://localhost:8080/wallets/1 -H "Content-Type: application/json" -d '{"balance":100.5}'
```

返回：
```json
{"message": "余额更新成功"}
```

再查一下确认：
```powershell
curl.exe http://localhost:8080/wallets
```

### 3.6 删除钱包

```powershell
curl.exe -X DELETE http://localhost:8080/wallets/2
```

返回：
```json
{"message": "钱包删除成功"}
```

### 3.7 校验测试

```powershell
# 缺少必填字段 → 400
curl.exe -X POST http://localhost:8080/wallets -H "Content-Type: application/json" -d '{"user_id":1}'

# 校验余额为负数（如果加了 gte=0）→ 当前没有校验
```
